# CHITRALIPI — Website

A responsive, static portfolio website for the CHITRALIPI creative brand. It uses plain HTML, CSS and JavaScript: no build tools, package installation, database or paid hosting required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the optional Google Fonts; the site otherwise works without external libraries.

## Before publishing
1. Open `index.html` in a text editor.
2. Find `hello@chitralipi.example` and replace it with your real public contact email.
3. Review all project descriptions and edit anything you want to change.
4. Save the file.

The email address is deliberately a placeholder. Do not publish it unchanged.

## Publish free with GitHub Pages
1. Sign in to https://github.com/ or create a free account.
2. Create a new **public** repository named `chitralipi` (or another name you prefer).
3. Extract this ZIP on your computer.
4. Open the repository on GitHub and choose **Add file → Upload files**.
5. Upload the contents of this folder (the `index.html`, `assets` folder, and `.nojekyll` file). Upload the contents, not the outer ZIP.
6. Commit the files to the `main` branch.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main`, folder `/ (root)`, then click **Save**.
10. Wait for the deployment to finish. Your site address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/chitralipi/`

If you name the repository exactly `YOUR-GITHUB-USERNAME.github.io`, the address will instead be:
`https://YOUR-GITHUB-USERNAME.github.io/`

## Updating the site
Edit `index.html`, `assets/css/style.css` or `assets/js/main.js`, then upload the changed files to the same repository and commit. GitHub Pages republishes automatically.

## Notes
- GitHub Pages is free for public repositories.
- This is a static website. It does not include a private admin dashboard, visitor database, online store or contact-form backend.
- The contact button uses the visitor's email app (`mailto:`); it does not send messages to a server.
- No analytics or tracking scripts are included.
- Keep personal phone numbers, home addresses and private information off the public site.
